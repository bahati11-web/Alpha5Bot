## 📁 Contenu du dossier

| Nom du fichier | Description |
|----------------|-------------|
| **`BandeauxPortailsBOT.sh`** | Script shell pour gérer automatiquement les bandeaux et portails sur les pages d’une catégorie |
| **`BandeauxPortailsBOT.js`** | Script JavaScript pour gérer automatiquement les bandeaux et portails sur les pages d’une catégorie |
| **`Interwiki-simple.py`** | Ajoute ou met à jour les liens vers **Simple English Wikipedia** |
| **`Interwiki-nl.py`** | Ajoute ou met à jour les liens vers **Wikikids (néerlandais)** |
| **`Interwiki-it.py`** | Ajoute ou met à jour les liens vers **Vikidia en italien** |
| **`Correct-wp.py`** | Corrige les liens `[[wp:{{PAGENAME}}]]` et `[[wp:{{FULLPAGENAME}}]]` en utilisant le titre réel de la page |
